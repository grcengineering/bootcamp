# Module 00 — Assessment Rubric

Each row is **Pass / Not-yet**. All rows must be **Pass** to clear the module. A Not-yet routes
the learner back to the named concept section.

| Criterion | Objective | Pass means | On Not-yet, return to |
|---|---|---|---|
| Control as claim | O3 | States the control as a single falsifiable "X is true of system Y" and names where its truth physically lives today | §4.1 |
| Inversion thesis stated | O1 | States the two arrows cold (legacy framework→…→audit vs reality→policy) without notes, in plain language, no "automation" crutch | §3, §4.2 |
| Five legacy problems | O2 | Scores the control against all five named problems, each addressed by name; no silent omissions | §4.3 |
| Principle ↔ problem link | O2 | Connects at least one of the five principles to the specific legacy problem it answers | §4.4 |
| Loop map with concrete LOCATE | O3 | Maps the same control through all seven loop stages; LOCATE names the actual system holding the truth | §4.6 |
| One-page inversion artifact | O4 | Produces the one-page legacy-vs-engineered analysis in the fixed shape; reality→policy inversion is explicit and the artifact is retained for the capstone | §4.2, §6 |

**Telemetry:** record each criterion's Pass/Not-yet per learner. Aggregate per-objective
pass-rate feeds the rot model — any objective below `assessment_passrate_threshold` flags the
**content** (not the learner) for revision.
