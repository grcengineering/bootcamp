# Accessibility Checklist (editorial gate — §7 anatomy: Accessibility)

Every module clears this before Publish. Plain-language and structure are first-class, not polish.

- [ ] **Alt text** on every image/diagram describing its *information*, not its appearance.
- [ ] **No color-only meaning.** Rot states, pass/fail, etc. always pair color with text/emoji
      and a label (🔴 "overdue", not red alone).
- [ ] **Heading structure is sane and sequential** (the 9-section anatomy); a screen reader can
      navigate by heading. No skipped levels for visual effect.
- [ ] **Tables have header rows**; columns are labeled; no purely visual layout tables.
- [ ] **Link text is descriptive** — never "click here" / bare URLs as the link text in prose.
- [ ] **Plain-language pass:** define terms on first use; expand acronyms once; short sentences
      for the load-bearing ideas.
- [ ] **Code blocks are fenced and language-tagged**; commands are copy-pasteable as plain text.
- [ ] **No reliance on audio/video alone** for a required concept — text carries the objective.
