# GRC Engineer — Generalist *(default track)*

**The object it engineers:** the whole control loop, end-to-end, across all four specialist
domains — the connective tissue.

## Jobs-to-be-Done
- Convert manual GRC toil into engineered systems so assurance is continuous, not point-in-time.
- Be the integration layer: make control/risk/evidence data flow across cloud, IdP, HRIS,
  ticketing, CI/CD.
- Translate between engineers, auditors, and leadership.

## Role Spine (deep)
Common Core at full depth, then **working depth across all four specialist spines** plus a spike
in **integration / data-pipeline engineering** (schema mapping, ETL, normalization, dashboards,
SQL + BI). Deep on: 01–07, 13, 14; working on 08–12.

## Role Capstone
**Ship one real control end-to-end across all loop stages** — designed-left, policy-as-code
enforced, evidence auto-collected, continuously monitored, OSCAL-expressed, owned as a product.
The synthesis capstone; the others are specializations of it.

> Sub-scale orgs collapse the five roles into 1–2 people — this track is how that compression is
> taught explicitly, not by accident.
