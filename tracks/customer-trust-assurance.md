# Customer Trust & Assurance Engineer

**The object it engineers:** the **customer-facing trust surface** — the security program
externalized for revenue. (The manifesto's "stakeholder-as-customer" value, made literal.)

## Jobs-to-be-Done
- Make security posture self-serve and instantly verifiable for prospects/auditors.
- Take security questionnaires/audits off the deal critical-path; position the company as a
  security leader.

## Role Spine (deep)
**Trust Center automation** · security-questionnaire/RFP automation (answer engine over a
maintained response DB / RAG) · customer-audit support tooling · gated attestation/report
distribution + access control · contractual/SLA evidence · public posture · **outward technical
communication**. Deep on: 05, 06, 13, 14; working on the Common Core, 12.

## Role Capstone
Automate the **customer trust loop**: a self-serve Trust Center fed by the *same* evidence
pipeline Compliance builds, with gated report distribution and a questionnaire-answer engine —
measured by reduction in manual questionnaire turnaround.
