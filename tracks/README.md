# Learning Tracks

Five role tracks share a placement-gated **Common Core** and Part I, then specialize on a
**Role Spine**, ship a **Role Capstone**, and **reconverge at a shared capstone showcase** where
every track demos its capstone to the others — preserving the generalist DNA the manifesto
insists on (*mindset, not silo*).

```
Common Core  ─►  Role Spine  ─►  Role Capstone  ─►  Cross-track electives
(everyone,       (modules this   (engineer one      (depth in an
 placement-       role goes       artifact specific   adjacent role)
 gated)           deep on)        to the role)
```

Each specialist track is defined by **the object it engineers** — not a vague blurb.

| Track | Engineers… (the object) | File |
|---|---|---|
| **GRC Engineer — Generalist** *(default)* | the whole control loop, end-to-end | [`generalist.md`](./generalist.md) |
| **Governance Engineer** | the policy & control architecture | [`governance.md`](./governance.md) |
| **Risk Engineer (1st + 3rd party)** | the risk models & risk/vendor data pipeline | [`risk.md`](./risk.md) |
| **Compliance Engineer** | evidence & audit-readiness | [`compliance.md`](./compliance.md) |
| **Customer Trust & Assurance Engineer** | the customer-facing trust surface | [`customer-trust-assurance.md`](./customer-trust-assurance.md) |

Depth per module per track is the [`coverage-matrix.md`](./coverage-matrix.md)
(**D** = Deep/author · **W** = Working/operate · **A** = Awareness/converse).

**Placement:** nobody starts at module 1 by default — each module's competence artifact is also
its placement test. Demonstrated competence skips the module; nobody re-learns the shell needlessly,
nobody skips the mindset.

> **Note (five, not six).** The README/Plan earlier said "six tracks"; every enumeration lists
> these five, and the Role-Competency Framework defines five. This repo treats it as five.
