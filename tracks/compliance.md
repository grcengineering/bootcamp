# Compliance Engineer

**The object it engineers:** **evidence & audit-readiness** — proof that controls operate,
produced automatically and continuously.

## Jobs-to-be-Done
- Make the org continuously audit-ready with zero manual evidence collection.
- Detect control gaps before auditors do; turn audits into exports, not fire drills.

## Role Spine (deep)
**Evidence-as-code** pipelines · **continuous controls monitoring** (control → check → evidence →
drift alert) · API evidence collection at scale · framework-mapping execution · automated gap
detection · audit-prep automation · IaC scanning in CI. Deep on: 01–07, 08, 10, 12, 13; working on 09.

## Role Capstone
Stand up a **continuous-controls-monitoring loop for one framework area**: automated checks →
versioned evidence store → drift alert → auditor-ready export, with **zero manual evidence toil**.

> Deep certification-framework fluency (SOC 2, ISO 2700x, FedRAMP, PCI-DSS, HIPAA, C5) is the
> governance backdrop; the *engineering* spike is evidence-as-code + CCM, not the certificates.
